# Dressed-State Spectroscopy of Proton Spins in Water Beyond the Rotating-Wave Approximation

[![DOI](https://img.shields.io/badge/DOI-10.5281/zenodo.19066699-blue)](https://doi.org/10.5281/zenodo.19066699)
[![Release](https://img.shields.io/github/v/release/ivoschulthess/dressedStates)](https://github.com/ivoschulthess/dressedStates/releases)
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/ivoschulthess/dressedStates/HEAD?labpath=analysis.ipynb)

This repository contains the experimental data and analysis code for the dressed spin-state measurements using the proton NMR apparatus, as presented in the publication:

I. Schulthess, A. Fratangelo, P. Hautle, et al., 
*Dressed-State Spectroscopy of Proton Spins in Water Beyond the Rotating-Wave Approximation*, 
accepted by Phys. Rev. Lett. (**2026**). 
DOI: [10.1103/kwg6-9vk3](https://doi.org/10.1103/kwg6-9vk3).

The official release is archived on **Zenodo**, while **Binder** allows users to explore the data and run or modify the analysis directly in their browser without installing any software. Both are accessible via the badges above.
